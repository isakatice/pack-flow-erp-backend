# PackFlow ERP - Backend API 📦⚙️

API RESTful robusta y escalable diseñada específicamente para la gestión integral, control operativo y cotización técnica automatizada en la industria del empaque, cartonaje y embalajes.

## 🚀 Características del Core Lineal
- **Modelado de Datos Avanzado:** Base de datos relacional normalizada para el manejo de suajes, tipos de flauta, resistencias de cartón y cálculo de áreas de material.
- **Arquitectura Modular:** Separación estricta de rutas, controladores, servicios y lógica de negocio para una escalabilidad limpia.
- **Seguridad:** Autenticación mediante JSON Web Tokens (JWT) y encriptación de contraseñas.
- **ORM Moderno:** Consultas optimizadas y migraciones controladas utilizando Prisma.

## 🛠️ Stack Tecnológico
- **Runtime:** Node.js
- **Framework:** Express.js
- **Base de Datos:** PostgreSQL
- **ORM:** Prisma ORM
- **Control de Versiones:** Git & GitHub

## 📂 Estructura de Base de Datos (Módulos principales)
- **Módulo de Clientes & Sitios:** Control de sucursales geográficas y datos de facturación.
- **Módulo de Cotizaciones:** Algoritmo de cálculo de costos basado en dimensiones de cajas, tipo de cartón, tintas aplicadas y mermas de producción.
- **Módulo Financiero:** Catálogo de cuentas bancarias de la empresa y flujos de pago.
